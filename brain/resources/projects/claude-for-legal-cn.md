# Claude for Legal 本土化 · regulatory-legal

## 是什么
Anthropic 开源了 `claude-for-legal`(12 个法律领域 Claude Code plugin + 5 个托管 agent 工作流,面向美国法)。一支多人团队组建了协作空间在做中国本土化,**项目代号 claude legal for China**。阿成在 2026-05-15 23:56 认领了其中的 `regulatory-legal`(监管法律)插件。

## 项目野心(超过纯翻译)
- 法律体系迁移:美国法 → 中国法(民法典/民诉法/PIPL/网安法/网信办规章...)
- 接口本土化:Slack/GDrive/Westlaw/CourtListener → 飞书/钉钉/腾讯文档/**元典 API**
- 多 Agent 运行时:Claude Code/Codex/Cursor/OpenClaw/Hermes/Kimi/Workbuddy 都跑
- 模块化安装 + 四层评测体系

## 阿成的独家位置
他有元典开放平台 35 个 API,**可以做 regulatory-legal 的 verified-citation backbone** —— 别的认领者做不了这层深度。这是这个活的核心 ROI 故事。
