# 元力工厂-For.Agents

> 法律AI产品的研发与运营中枢。三条核心产品线：法律元力（Skill平台）、元典开放平台（API）、Amicus（法律智能体）。

## 三代产品架构

华宇元典经历了三代法律AI产品的演进：

```
阶段一：元典睿核（2016-）
  └── 知识图谱 + 结构化数据
  └── 特点：稳定但难更新、不能泛化

阶段二：元典问达（知识库融合）
  └── DeepSeek-R1 驱动
  └── 低幻觉率法律推理自动化

阶段三：Amicus 法律智能体（当前）
  └── 法律工作任务执行交付的自动化
  └── 能完成：文档编辑/审核/生成、数据总结解析、模板写作
  └── 产品：ami.ailaw.cn
```

## 三条产品线

### 法律元力（Skill平台）

**官网**：https://yuanli.ailaw.cn
**定位**：法律人的智能体加速器，Skills平台

**核心Skill矩阵**：
- 合同审查（四层/三层检查版）
- 元典法律检索（5种检索模式）
- 中国法律研究助手
- 诉讼分析、法律文书生成、法规检索、专利分析
- 广告合规审核、劳动仲裁管家、法律风险可视化
- 诉讼可视化时间轴、合同生成、域外法律研究
- 法外功夫（商业分析框架）、法院短信识别与文书下载

**技术资产**：
- Legal Skill Creator：`product/exploration/legal-skill-creator/`（450+行指南 + 74KB参考资料）
- API文档：`code/docs/`（元典法律检索5个核心接口完整文档）

### 元典开放平台（API服务）

**官网**：https://open.chineselaw.com
**定位**：一站式API服务，助力业务创新

**技术栈**：
| 组件 | 技术 |
|------|------|
| 后端 | Java 17 + Spring Boot 3.2 + Spring Cloud Alibaba |
| 微服务 | Nacos（注册+配置）+ Redis（缓存+限流）+ Motan（RPC） |
| 数据库 | PostgreSQL 15 |
| 前端 | Vue3 + TypeScript + Vite + Element Plus |
| API网关 | Spring Cloud Gateway（端口8080） |

**微服务架构**（5个服务）：
```
gateway (8080)     → API网关，API Key认证+路由+限流+余额扣减
user-service (8081) → 用户/Key管理
api-service (8082)  → 接口广场/API信息
order-service (8083) → 订单/充值
admin-service (8084) → 后台管理
```

**核心数据库表**：t_user / t_api_key / t_api_category / t_api_info / t_recharge_product / t_order / t_call_log / t_balance_log

**部署**：Docker Compose本地开发；K8s生产环境

### Amicus（法律智能体）

**官网**：https://ami.ailaw.cn
**定位**：法律人一站式AI智能体伙伴

**核心特点**：
- 融合多模型自主智能
- 可调用海量知识 + 专业工作流
- 集成用户知识、自主记忆、习惯养成

**相关项目分散在**：
- `产品经理/Amicus小程序/`（微信小程序版）
- `方案/Ami/`（销售宣讲PPT、产品图）
- `产品经理/Ami移动版演示评审/`
- `产品经理/Ami小程序-存档/`
