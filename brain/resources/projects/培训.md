## 演讲知识体系

### AI产品进化认知框架（常成原创）

用于给法律人讲解AI演进，已在不同场合反复使用：

```
阶段1：问答式AI（单次交互）→ 豆包/Kimi/ChatGPT
阶段2：带记忆的AI（多轮对话）→ 上下文保留
阶段3：智能体Agent（任务闭环、工具调用）→ OpenClaw/MyAgent
```

**核心问题**：智能体和豆包有什么区别？
→ 感知→思考→执行→反馈的自主循环，数字员工 vs 对话助手

### 智能体三大架构（2026年认知）

| 架构 | 出品方 | 开源时间 | 特点 |
|------|--------|---------|------|
| **OpenClaw**（小龙虾） | 奥地利工程师Peter Steinberger | 2025年11月 | GitHub史上增长最快；获电脑底层权限；腾讯WorkBuddy同类 |
| **Hermes Agent**（爱马仕） | AI实验室Nous Research | 2026年2月 | GitHub 4万+星；持久运行；自我成长；跨会话记忆 |
| **MyAgent** | MyAgents | — | 桌面端；本地化；多Tab并行；12+模型支持；MCP集成 |

### 华宇元典产品三部曲（对外宣讲用）

从历史维度帮助听众理解公司产品线：

```
元典睿核（2016-）→ 知识图谱，稳定但难更新
元典问达 → 知识库+DeepSeek-R1，低幻觉法律推理
Amicus法律智能体 → 工作任务执行交付自动化
```
