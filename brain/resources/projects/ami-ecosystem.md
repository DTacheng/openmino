# Ami 生态

> Amicus是华宇元典的的法律智能体产品，定位于"法律人一站式AI智能体伙伴"。产品线包含多个形态：微信小程序、移动版、销售宣讲材料。

**官网**：https://ami.ailaw.cn

## 产品定位

**一句话定位**：法律人一站式AI智能体伙伴

**核心特点**：
- 融合多模型自主智能
- 可调用海量知识 + 专业工作流
- 集成用户知识、自主记忆、习惯养成

Amicus 2.0  → 销售宣讲PPT + 产品全景图
