# 元典开放平台

## 定位（2026-05-12 更新，拔高）

**智能体时代的法律数据基础设施。**

面向全行业法律人，以及财务、审计、合规、投资、政府等**各部门各场景中需要法律法规数据的智能体使用者**——而非只服务开发者或律所 IT。

在创新大赛叙事中对应"**Know-what 事实底座**"：通用大模型在法律事实层有幻觉，开放平台作为可信赖的事实供给侧，解决"AI 怎么真正懂中国法"的问题。

**与法律元力站的关系**：法律元力 Skill 库（know-how）+ 元典开放平台 API（know-what）= 法律 AI 双轮，Skill 提供方法论、API 提供事实。同时也是元典 Amicus 的底层数据与能力支撑。

**用户画像（避免再写窄）**：
- ✅ 律所律师、企业法务、合规审计、财务投资、政府监管……任何需要权威法律数据的智能体使用者
- ❌ 不要写成"只面向法律科技开发者 / 律所 IT 团队"

## 核心接口（5 个）

| 接口      | 路径                       | 用途                          |
| ------- | ------------------------ | --------------------------- |
| 法条语义检索  | `POST /search`           | 自然语言查法条，支持效力级别+时效性筛选        |
| 法条关键词检索 | `POST /search_keyword`   | 关键词查法条，支持日期范围、发布/实施日期筛选     |
| 法条详情查询  | `POST /search_ft_info`   | 按法规名称+法条序号查具体法条             |
| 案例关键词检索 | `POST /search_al`        | 关键词查案例，支持案号/案由/法院/地域/文书种类筛选 |
| 案例向量检索  | `POST /search_al_vector` | 语义相似度检索案例                   |

## 关键参数速查

**效力级别可选值**：宪法、法律、司法解释、行政法规、监察法规、部门规章、党内法规、军事法规规章、地方性法规、地方政府规章等 17 种

**时效性可选值**：现行有效、失效、已被修改、部分失效、尚未生效

**案件类别可选值**：刑事案件、民事案件、行政案件、执行案件、管辖案件等 10 种

## 认证方式

**新平台（合规）**：API Key 放在 HTTP Header `X-API-Key` 里：
```
POST https://open.chineselaw.com/open/law_vector_search
Header: X-API-Key: {你的api_key}
```

**旧平台（已废弃）**：通过 URL 参数 `?api_key=` 传递，存在日志泄露风险，不合规。
