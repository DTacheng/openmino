# 智能体架构

## AI 产品演进三阶段

| 阶段 | 特征 | 比喻 | 代表产品 |
|------|------|------|---------|
| 问答式 AI | 一问一答，无记忆无上下文 | 政务大厅问路 | 早期 ChatGPT、早期豆包 |
| 带记忆的 AI | 多轮对话，记住上下文 | 法律顾问热线 | 豆包、Kimi、DeepSeek |
| 智能体 Agent | 任务闭环，自主执行 | 招了一个实习生 | OpenClaw、MyAgent、Hermes |

**质变点**：从"能说话"到"能干活"。智能体有了"手脚"——能在电脑上实际操作。

## 智能体定义

> 一个能感知环境、自主思考、调用工具、执行任务，并根据结果自我调整的 AI 系统。

**四步自主循环**：
1. **感知** — 读文件、看邮件、接收消息
2. **思考** — 理解意图，拆解步骤
3. **执行** — 操作电脑，调用 API，生成文档
4. **反馈** — 发现问题，自我修正

关键词是「自主」——不需要人盯着，自己跑。

## 三大主流架构对比

| 维度 | OpenClaw | Hermes Agent | MyAgent |
|------|----------|-------------|---------|
| 定位 | 桌面端个人 Agent | 服务器端持久 Agent | 桌面端用户中心 Agent |
| 核心理念 | 任务执行、工具调用 | 自我成长、技能沉淀 | 用户中心、共同记忆 |
| 记忆 | 本地 Markdown 存储 | 多层级记忆系统 | 三层记忆 + 持久 Session |
| 部署 | 本地电脑 | 服务器/云端 | 本地电脑 |
| 数据安全 | 本地优先，但插件风险高 | 服务器端，运维要求高 | 本地优先，开源可审计 |
| 生态 | ClawHub 13000+ skills | 自主技能沉淀 | 法律元力等垂直 Skill 库 |
| 模型 | 多模型 | 多模型 | 12+ 模型 |
| IM 集成 | 50+ 平台 | Telegram/Discord/Slack等 | 飞书/钉钉/Telegram/微信 |
| 开源协议 | MIT | MIT | Apache-2.0 |

## 判断工作是否适合智能体的标准

1. **工作能否在电脑上完成闭环？** 数字化空间内的操作（写文书、查案例、审合同）→ 适合
2. **有没有重复性？** 每月类似的合同审查、每周类似的法律意见 → 回报最高

**正确预期**：智能体是很强的实习生，不是合伙人。处理 80% 基础性重复性工作，释放人做 20% 需要专业判断的事。
