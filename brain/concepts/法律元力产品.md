# 法律元力产品

## 定位

法律元力（Yuanli Vault）是中国首批面向法律人的 AI Agent 技能库。定位为「法律人的智能体加速器」，把散落在 GitHub、个人博客和各种开源社区的优质法律 AI 技能统一收录，让法律人像逛应用商店一样找到、安装自己需要的 AI 技能。

**官网**：https://yuanli.ailaw.cn
**出品方**：华宇元典

## 产品形态

每个「技能」是一个 AI Agent Skill 包——包含结构化提示词、参考知识库、配套脚本工具。安装后可在 Claude Code、OpenClaw 等 Agent 中直接使用。

**三步使用**：下载技能包 → 查看源码 → 一键安装到 Agent

## Skill 覆盖领域

| 领域 | 代表 Skill |
|------|-----------|
| 法律研究 | 中国法律研究助手 |
| 合同与交易 | 合同审查（四层/三层检查版）、合同生成 |
| 合规与审查 | 合规检查 |
| 尽职调查 | — |
| 争议解决 | 诉讼分析、劳动仲裁管家 |
| 法律文书 | 法律文书生成器（泛法律文书） |
| 知识管理 | 法律风险可视化 |

## 核心贡献者

- **Anthropic 官方**：Claude 官方 GitHub 仓库开源的法律类 Skill
- **华宇元典**：聚焦结合元典法规案例 API 的法律检索类 Skill
- **法律 AI 博主**：杨卫薪律师、杜思敏律师、潘淑燕律师、积成、刘冲律师等 7 位

## 数据资产（创新大赛视角）

法律元力的数据要素价值：

| 数据类型 | 内容 | 价值 |
|---------|------|------|
| 法规数据 | 宪法、法律、法规、司法解释等 | 法律检索基础 |
| 案例数据 | 指导性案例、公报案例、典型案例 | 司法实践参考 |
| 合同数据 | 模板库、条款库、风险点库 | 合同审查依据 |
| 工作流数据 | 检索/审查/合规工作流 | 标准化输出 |
| 知识图谱 | 法条互引、风险矩阵、用户画像 | 智能化服务 |
