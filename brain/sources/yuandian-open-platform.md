# 元典开放平台 — 接口清单

> 共 36 个公开接口，分 4 个分类。访问入口：[接口广场](https://open.chineselaw.com/api-square)，详细文档在「文档」菜单。
> 平台用积分制计费（详见各接口右上角），需注册 Passport 账号 + 创建 API Key + 充值积分后调用。
> **MCP Server**：已建 3 个（yuandian-law / yuandian-case / yuandian-company），约 35 个 MCP Tool，生产环境 `/mcp` 路由暂重定向到首页。
> **福利活动期**：2026-04-27 至 2026-07-26，新用户注册送 51,000 积分（50,000 活动 + 1,000 默认）。

## 关键观察

- **企业类是绝对主力**（26/36 ≈ 72%），覆盖工商→知产→涉诉→执行→经营异常全链路
- **企业检索 1 积分定位 + 5/10 积分拉详情** 是设计模式：先低价定位 ID，再按需取详情
- **幻觉检测 50 积分**最贵，是 AI 时代的新接口——AI 答法律问题后用它核验"是不是编的"
- **语义检索 vs 关键词检索**并存：语义适合模糊问题、关键词适合精准命中
- 旧记忆里只写过 `law_vector_search`（语义检索），35 个接口中只覆盖到 1 个
