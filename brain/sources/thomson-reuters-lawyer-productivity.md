# Thomson Reuters — Future of Professionals 报告

## 关键摘录

### 核心发现（已验证 ✓，有重要上下文）

**AI 有潜力在5年内为专业人士每周节省12小时。**

- **发布时间**：2024年7月9日
- **调查规模**：全球2200+ professionals（法律、税务、风险合规）
- **关键时间节点**：12小时/周是**2029年的目标**（5年预测），而非当前现状
- 即时目标（1年内）：**4小时/周**

### 律师具体数据

| 指标 | 数值 |
|------|------|
| 5年目标节省时间 | 12小时/周 |
| 即时目标（1年内） | 4小时/周 |
| 年化节省 | 约200小时（基于12小时/周） |
| 对团队影响 | 每10人团队 = 增加1名同事产能 |
| 美国律师经济价值 | 每年最高 $100,000 增加可计费时间 |
| 英国律师节省 | 每律师约£12,000；全行业 £2.4bn |

### 当前 AI 使用率（2025）
- **26%的法律专业人士**已在使用 GenAI（2025年，相比2024年的14%翻倍）
- 77%的专业人士认为 AI 在未来5年将产生高或变革性影响

### CoCounsel 实际案例
使用 Thomson Reuters CoCounsel Legal 的法律团队报告已节省**每周12小时**——相当于在不增加人手的情况下增加10%产能。
