# 腾讯 — WorkBuddy AI Agent 发布

## 关键摘录

### 发布信息（已验证 ✓）

- **发布日期**：2026年3月9日
- **发布团队**：腾讯 Cloud CodeBuddy 团队
- **产品定位**：全场景 AI Agent（对标 OpenClaw）
- **内置 Skill 数量**：20个

### 主要功能

- 完全兼容 OpenClaw
- 支持多 AI agent 并行运行
- 聚焦企业工作场景
- 解决大模型在终端部署的复杂性问题

### 战略意图

腾讯总裁刘炽平（Martin Lau）表示：
> "我们希望在微信中创建 AI agent，利用微信与用户的紧密联系。"

### 与 OpenClaw 的关系

- WorkBuddy **完全兼容 OpenClaw**
- 可视为腾讯版的 OpenClaw 解决方案
- 反映了 OpenClaw 作为生态标准的影响力
