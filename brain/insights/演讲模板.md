# 演讲模板

## 标准演讲流程（已验证）

从宝鸡律协和政法大学两次演讲中提炼的标准流程：

```
1. 项目上下文.md    ← 定义受众、场景、约束
2. 研究素材.md      ← 深度调研，收集数据和案例
3. 逐字稿.md        ← 基于素材写完整演讲稿
4. PPT              ← 基于逐字稿生成演示文稿
5. 演讲/验证        ← 执行并收集反馈
```

## 逐字稿结构模板

### 60 分钟版（律协/行业培训）

| 部分 | 内容 | 时长 | 字数 |
|------|------|------|------|
| 第一部分 | 打开视野——概念引入 | ~15分钟 | ~3,500字 |
| 第二部分 | 主流方案对比 | ~15分钟 | ~4,000字 |
| 第三部分 | 实操演示 | ~15分钟 | ~3,000字 |
| 第四部分 | 产品生态介绍 | ~8分钟 | ~1,800字 |
| 第五部分 | 收尾+行动号召 | ~5分钟 | ~1,500字 |

### 30 分钟版（校园分享）

| 部分 | 内容 | 时长 |
|------|------|------|
| 引言 | 破冰+自我介绍 | 2-3分钟 |
| 技术背景 | AI进化+技术趋势 | 5-6分钟 |
| 行业观察 | 各群体变化 | 5-6分钟 |
| 展望 | 趋势和机会 | 5-6分钟 |
| 行动建议 | 具体行动+竞争力 | 8-10分钟 |
| 收尾 | 上价值 | 2-3分钟 |

## 开场破冰模板

```
举手调查（三层递进）：
1. "用过豆包的请举手？"          ← 大多数人举手，建立共识
2. "用过Kimi或DeepSeek的请举手？" ← 部分人举手，区分程度
3. "听说过'小龙虾'的请举手？"    ← 少数人举手，引出主题
→ 不管举没举手，"你们每天都在用AI"
```

## 收尾行动号召模板

```
三个今天就能做的事：
1. 下载一个 [产品名]，花30分钟走一遍安装流程
2. 上 [平台名] 看一看，找到一个最相关的功能试一试
3. 在你的 [组织] 内部做一次分享
```
