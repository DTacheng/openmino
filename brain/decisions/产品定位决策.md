# 产品定位决策

## 决策：法律元力定位为「法律人的 Skill 百宝箱」

### 选择

把法律元力定位为**技能聚合平台**（Skill 的应用商店），而非自研全栈法律 AI 产品。

### 理由

1. **生态策略**：不做封闭产品，做开放平台。汇聚 Anthropic 官方、法律 AI 博主、华宇自研三方力量
2. **差异化**：国内没有专门面向法律人的 AI Skill 聚合平台，是蓝海
3. **低门槛**：不会写代码的律师也能用——一键下载安装即用
4. **兼容性**：不绑定特定 Agent，OpenClaw、Claude Code 等均可安装
5. **数据资产变现**：华宇元典的法规案例数据通过 API（元典开放平台）+ Skill（法律元力）双通道变现

### 产品生态分工

| 产品 | 定位 | 面向谁 |
|------|------|--------|
| 法律元力 | 技能库（应用商店） | 法律人（终端用户） |
| 元典开放平台 | 数据底座（API） | 开发者/IT团队 |
| Amicus | 一站式 AI 伙伴（前端入口） | 法律人（深度用户） |
| MyAgent | 通用 Agent 框架 | 所有人（基础设施） |

**一句话**：MyAgent 做框架、法律元力做技能、元典做数据、Amicus 做体验。

### 创新大赛定位

参赛「数据要素价值创新」赛道，核心叙事：
- 法律数据（法规+案例+合同+工作流+知识图谱）是 AI Skill 的燃料
- 法律元力将数据资产转化为可直接使用的法律 AI 能力
- 贡献者生态（7 位博主 + Anthropic + 华宇）验证了平台价值
